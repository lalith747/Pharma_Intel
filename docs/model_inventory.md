## Evidence and interpretation

- Hugging Face token-classification models assign labels to tokens/spans. A NER checkpoint is only usable for our intended labels when its exact label inventory and annotation conventions match the extraction target. See the [Transformers token-classification guide](https://huggingface.co/docs/transformers/tasks/token_classification).
- The BioCreative V CDR benchmark uses PubMed abstracts and Chemical/Disease annotations; disease extraction is not equivalent to adverse drug reaction detection. See the [original corpus paper](https://doi.org/10.1093/database/baw068).
- The ADE corpus was designed for drug-related adverse-event extraction from PubMed/MEDLINE case reports. Existing work describes 4,272 event sentences from 1,644 abstracts with 6,821 annotated drug-condition relations; the exact dataset release and negative sampling must be checked before model training. See [ADE corpus extraction work](https://pmc.ncbi.nlm.nih.gov/articles/PMC3973995/) and [ADE corpus details](https://pmc.ncbi.nlm.nih.gov/articles/PMC3599676/).
- BioScope provides annotations for negation/speculation cues and their linguistic scope, but the benchmark is not a direct gold standard for the relation classes in PharmaIntel. See the [BioScope paper](https://aclanthology.org/W08-0606/).
- BioRED is a multi-entity, document-level biomedical relation resource; it includes chemicals and diseases, but its relation taxonomy is not the same as drug-caused ADR labels. It can inform methods, not silently supply causal labels. See [BioRED](https://arxiv.org/abs/2204.04263).

## Benchmark protocol before model selection

1. Freeze a small, manually reviewed, PMID-disjoint sample and annotation guide before model comparison.
2. Record exact model revision, model-card URL, architecture, tokenizer, label map, task head, license, weight format/size, maximum input length, and download date.
3. Measure inference latency, peak RAM, and load behavior on this CPU machine; estimate GPU needs only for fine-tuning if needed.
4. Compare task-matched checkpoints and transparent lexical/rule baselines on the same split and strict span-level or pair-level metrics.
5. Keep entity extraction, relation labels, and assertion/context labels as separate targets. Never convert co-occurrence, semantic similarity, or a sentence-level ADE label into proof of causality.
6. Document cross-corpus/domain limitations and inspect false positives/negatives before selecting any model.

## First shortlist, not final selection

For the first controlled NER benchmark, compare `Glasgow-AI4BioMed/bioner_bc5cdr` (PubMed-domain, Chemical/Disease) with `d4data/biomedical-ner-all` (broad Medication/Disease_disorder/Sign_symptom labels). Consider OpenMed PharmaDetect as a chemical-only third comparator after verifying its card claims and BF16 CPU support. Use exact mention spans and evaluate drug mentions and ADR mentions separately. Pair-level RE and negation/speculation require a separate candidate/annotation decision.
